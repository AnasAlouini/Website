4-Week Beginner Running Plan

From zero to 25 minutes non-stop — follow each week step by step.

Week Monday Wednesday Friday Sunday
Week 1 Walk 20 min Run 5 min + Walk 15 min Walk 20 min Run 5 min + Walk 20 min
Week 2 Run 10 min + Walk 10 min Run 12 min + Walk 8 min Rest Run 15 min
Week 3 Run 15 min Run 18 min Rest Run 20 min
Week 4 Run 20 min Run 22 min Rest Run 25 min 🏁
💡 Tips: Always warm up with a 5-minute brisk walk before each session. Cool down and stretch after every run. If you feel pain — not just tiredness — take an extra rest day. Drink water before and after every session.
